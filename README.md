# 🔐 Stylish Caesar Cipher Web App

A visually appealing web application that allows users to encrypt text using the classic Caesar Cipher technique. Users can enter a message, choose a shift key, and receive the encrypted result — all in a sleek, responsive interface.

---

## ✨ Features

- 🔢 Encrypts any text using Caesar Cipher logic
- 🎨 Modern UI with glassmorphism and gradient background
- 📱 Fully responsive and interactive
- 🖱️ Simple interface with just a few clicks
- 🚫 Input validation for shift range (1–25)

---

## 🖥️ Technologies Used

- **HTML5** – Structure of the web page
- **CSS3** – Stylish layout and animations (glass effect, hover states)
- **JavaScript** – Caesar Cipher logic & DOM interaction
